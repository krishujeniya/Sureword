              1. How does Budget-Constrained Selective Spoken Clarification work?
              

                
Standard voice interfaces either reprompt the user for every field (causing severe cognitive burden) or silently accept ASR transcriptions (admitting corrupted health records). Sureword evaluates a risk assessment function $R(f) \in [0.0, 1.0]$ for each field:

                
    
                  
  • Format & Range Violations: $R=0.9$ (e.g., physiological age > 120 or invalid calendar dates like Feb 30).
    • 
                  
  • Out-of-Dictionary Entities: $R=0.7$ (village names extracted purely via markers).
    • 
                  
  • Proposed Valid Candidates: $R=0.25 - 0.35$.
    • 
                  
  • Confirmed / Edited Entities: $R=0.0$ (no re-prompting).
    • 
                

                
Policy $P$ selects the single highest-risk entity ($\arg\max_{f} R(f)$) needing clarification and synthesizes an ASHA clarification prompt via Gnani Timbre, ensuring field accuracy is doubled at a deterministic 1.0 prompt/form cost ceiling.

              

            


            

              2. Why deterministic parsing instead of generative LLMs for medical forms?
              

                
Frontline healthcare records require absolute auditability and zero hallucination. Generative LLMs can invent dates, normalize names into nonexistent entities, or hallucinate physiological parameters under ambiguous audio. Sureword uses deterministic regex, Devanagari digit converters, dictionary matching, and physiological bounds (1-120 years) to guarantee that every saved field traces directly to spoken spans.

              

            


            

              3. What is the Action-WER Orthogonality Theorem ($WER \perp \text{Accuracy}$)?
              

                
In clinical documentation, Word Error Rate (WER) is orthogonal to downstream action accuracy: a transcription with 5% WER that corrupts only patient age (e.g. 15 to 50) produces a 100% clinically invalid visit record, whereas a 25% WER transcription that misses filler words ("जी", "है", "का") produces a 100% correct form. Therefore, Sureword measures exact entity match with 95% Wilson Score Confidence Intervals.

              

            


            

              4. How is frontline sovereign data privacy guaranteed?
              

                
Sureword adheres to strict sovereign privacy standards: zero third-party tracking scripts, zero client API key exposure, ephemeral serverless execution on Vercel Edge with local SQLite persistence in isolated /tmp directories, and cryptographic SHA-256 integrity hashing for all voice recordings.

# Product inventory

Sureword is a single-product research web app, with an introductory product page around the existing workspace. Audience: ASHA/ANM workflow researchers, challenge reviewers, and developers exploring selective voice-to-form clarification. Main job: dictate fictional visit details, resolve uncertain fields, review, save, and export.

| Attribute | Verified repository source / value |
| --- | --- |
| Product | Sureword, existing blue/navy shield-wave logo and favicon in `src/sureword/static/` |
| Runtime | FastAPI, Python, native HTML/CSS/JavaScript; `pyproject.toml`, `app.py` |
| Speech | Gnani Prisma STT and Timbre TTS adapter; credentials required for live use |
| Languages | 11 speech/localized workspace options in `languages.py` and `app.js`; overview is English |
| Fields | Name, age, village, visit date; optional gender and symptoms; `contracts.py`, `parser.py` |
| Workflow | Versioned drafts, targeted clarification, explicit review/commit, SQLite records, CSV/JSON export |
| Availability | Research prototype; not approved for clinical use; no auth; fictional inputs only |

All introductory copy derives from the parser, policy, state machine, README, and existing app behavior. Sample transcripts and answers are explicitly fictional. Provider fixture status is explicit. Serverless `/tmp` SQLite is temporary and is not suitable as durable patient storage.
